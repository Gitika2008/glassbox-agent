# GlassBox Agent
### Explainable AI for Scholarship Allocation
Built for SingularityNET x Omega x BASIX.Market Hackathon 2026

## What it does
Most AI gives you an answer. GlassBox gives you the answer AND shows every reasoning step behind it.

## Tech Stack
- MeTTa — Symbolic reasoning rules
- Python + FastAPI — Agent logic and API
- Flutter — Frontend UI
- Docker — Containerized backend

## How to run
Backend: docker compose up --build
Frontend: cd flutter_app && flutter run

## AI Disclosure
- Claude used for code assistance
- MeTTa/Omega for symbolic reasoning
